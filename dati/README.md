# Dati reali

Questa cartella contiene **l'unico materiale fattuale** che il generatore può usare oltre ai claim pubblici del sito. Tutto il resto è vietato inventarlo.

| File | Cosa contiene |
|------|---------------|
| `insight-trattative.md` | Numeri aggregati e anonimi dalle trattative analizzate |
| `clienti-e-risultati.md` | Clienti o settori citabili, con risultati reali |
| `episodi-trattative.md` | Scene reali di trattative, anonimizzate |

## Regole
- Il generatore usa solo le righe con **Approvato: sì**.
- Ogni riga ha una fonte e una data.
- Gli episodi sono anonimizzati: nessun nome, azienda o dettaglio che renda riconoscibile il cliente o il venditore, salvo autorizzazione scritta.
- Quando un dato viene usato in un post, si scrive il nome del post nella colonna "Usato in", così si evita di riusarlo troppo presto.
